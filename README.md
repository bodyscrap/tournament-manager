# サバ管

サバイバル大会向けのトーナメント管理アプリです。  
Tauri + React + TypeScript で構成されたデスクトップアプリで、以下を一貫して管理できます。

- 大会作成 / 大会コード管理
- 参加者・管理者のコード発行
- ブラケット進行（試合状態遷移、DQ、強制敗北、結果修正）
- QRコードによる検索・確認
- 参加者カード / 管理者カードの画像出力（単体・A4シート）

---

## 主な機能

### 1. 大会管理
- 大会コード（4桁）を手入力またはランダム決定
- 大会形式（シングル / ダブル）
- 参加上限
- デフォルトプレイヤーサイド（上1P / 上2P / ランダム）
- 使用キャラ入力モード（自由入力 / リスト選択）

### 2. 参加者管理
- 参加者の追加・削除・名前編集
- シード交換 / ランダム抽選
- 参加者コード（固定桁）発行
- 参加者カード表示（名前 / コード / QR / 属性）

### 3. 管理者管理
- 管理者の追加・削除・名前編集
- 管理者コード（固定桁）発行
- 管理者カード表示（名前 / コード / QR）

### 4. ブラケット進行
- 試合状態遷移
  - 未決定
  - 準備完了
  - 試合中
  - 結果確定
- スコア入力
- DQ指定
- 強制敗北指定
- 結果修正

### 5. 認証と監査
- DQ/強制敗北の確定時に確認コード入力
- 確認コードは1入力欄
- 強制敗北とDQが同時指定された場合は強制敗北を優先
- 実行情報を監査ログとして保存

### 6. QR連携
- 試合検索でQR読み取り
- 確認コード入力でQR読み取り
- QRがJSON形式でも、必要コード（参加者 / 管理者コード）を自動抽出して入力

### 7. カード画像出力
- 各カードから個別画像保存
- 全参加者 + 全管理者をA4相当シートPNGとして出力
  - A4中央90%領域
  - 5行 x 2列（1枚10カード）
  - 10件ごとに分割保存

個別カード保存名は次の形式です。

`[大会コード]_[大会名]_[ユーザ名].png`

## 画面ごとの使い方

### 大会一覧
1. 大会を新規作成します。
2. 既存大会を選択して管理画面へ進みます。

### 大会管理
1. 大会コード・形式・参加上限などを設定します。
2. 参加者を追加します。
3. 必要に応じて管理者カード画面で管理者を追加します。
4. ブラケットを生成します。

注記:
- 試合追加はブラケット画面側で行います（大会管理画面の試合追加機能は廃止）。

### ブラケット
1. 試合を開き、状態遷移とスコア入力を行います。
2. DQや強制敗北が必要な場合は設定します。
3. 確認コード欄に対象コード（またはQR）を入力して確定します。
4. 必要に応じて結果修正を行います。

### 参加者カード / 管理者カード
1. 各カードの「画像保存」で個別保存します。
2. 「全参加者+全管理者をA4シート画像で保存」で印刷用シートを生成します。

## 開発環境セットアップ

### 前提
- Node.js 18+
- Rust（Tauriビルドに必要）
- Windows（ターゲット想定）

### インストール

```bash
npm install
```

### 開発起動

```bash
npm run tauri dev
```

### ビルド

```bash
npm run build
```

## 補足
- カメラ読み取りは `navigator.mediaDevices.getUserMedia` を利用します。
- QR検出は環境差異を考慮し、フォールバックを含む実装になっています。
