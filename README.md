# サバ管

Savaki式トーナメント管理アプリ、略してサバ管です。  

以下を一括管理できます。

- 各種設定での大会作成&記録
- 参加者・管理者のIDおよびユーザーコード発行
- 使用キャラクターリストの管理
- ブラケット進行

---

## 主な機能

アプリのタブ毎の機能を説明します。  

### 1. 大会一覧

作成済みの大会の一覧を表示します。  
ここで選択した大会が操作・閲覧の対象になります。  
また、こちらの画面から新規の大会の作成も可能です。  

### 2. 使用キャラリスト

使用キャラリストの管理ができます。  

- 使用キャラリストの新規作成
- リスト名の編集
- リストへのキャラの登録/編集/削除  
- 既存リストのコピー

### 3. 大会管理

大会の作成および作成した大会へのプレイヤー登録が可能です。  

**大会作成機能**  

- 大会コード(4桁)を手入力またはランダム決定
- 大会形式(シングル / ダブル)
- 参加上限人数の設定(Max 256人)
- デフォルトプレイヤーサイド（上1P / 上2P / ランダム）
- 使用キャラ入力モード（自由入力 / リスト選択）

設定はブラケット作成前であれば変更可能です。  

**参加登録機能**  

- プレイヤー名、使用キャラを設定しての参加登録
- 参加登録済みのプレイヤー情報の編集
- 参加者の削除
- ランダム抽選
- ブラケットの作成

ブラケットは1大会につき1回のみ作成可能です。  

### 4. ブラケット

ブラケット進行の管理ができます。  

- 試合状態遷移
  - 未決定
  - 準備完了
  - 試合中
  - 結果確定
- プレイヤーサイドの再設定
  - 現在の設定からの1P/2Pの入れ替え
  - ランダム再設定
- スコア入力&勝敗確定
- DQ機能
  - 対象参加者 or 管理者のユーザコード入力で確定
- 強制敗北機能
  - 管理者のユーザコード入力で確定
- 結果修正
- 試合検索
  - プレイヤー名&試合状態での検索
- プレイヤー途中追加機能
  - Winners Round1にのみ追加可能
  - 追加後に強制敗北させれば疑似的にLosersスタートも可能
- 対戦カード操作
  - カード内の任意の場所をクリックして詳細を開く
- Winners Round1組み合わせ変更機能
  - Ctrl + ドラッグ&ドロップでプレイヤーの入れ替えが可能
- ユーザーコード取り込み機能
  - 2次元バーコードでのユーザーコードの読み取りが可能

### 5. 参加者カード

参加者カードの確認と画像保存ができます。

- 参加者カードの個別保存
  - 事前に配布してスマートフォンで表示して使用する想定
  - `[大会コード]_[大会名]_[ユーザ名].png`でダウンロードフォルダに保存
- 参加者&管理者カードの一括保存
  - 印刷用にA4シートに複数カードを配置して保存する想定  
  - 1ページあたり10カード(5行x2列)で保存
  - `[大会名]_A4_sheet_[ページ数]_of_[総ページ数].png`でダウンロードフォルダに保存

### 6. 管理者カード

管理者カードの管理ができます。  

- 管理者の追加/編集/削除
- 管理者カードの個別保存
  - 事前に配布してスマートフォンで表示して使用する想定
  - `[大会コード]_[大会名]_[ユーザ名].png`でダウンロードフォルダに保存
- 参加者&管理者カードの一括保存
  - 印刷用にA4シートに複数カードを配置して保存する想定  
  - 1ページあたり10カード(5行x2列)で保存
  - `[大会名]_A4_sheet_[ページ数]_of_[総ページ数].png`でダウンロードフォルダに保存

## 画面ごとの使い方

### 大会一覧

1. 新しく大会を作成した場合は大会を新規作成します。
2. 既存大会の操作/閲覧を行いたい場合は選択して管理画面へ進みます。

### 大会管理

1. 大会コード・形式・参加上限などを設定します。
2. 参加者を追加します。
3. 必要に応じて管理者カード画面で管理者を追加します。
4. ブラケットを生成します。

注記:

- 試合追加はブラケット画面側で行います。  

### ブラケット

1. 対戦カード内の任意の場所をクリックして試合を開き、状態遷移とスコア入力を行います。
2. DQや強制敗北が必要な場合は設定します。
3. 確認コード欄に対象コード（または2次元バーコード）を入力して確定します。
4. 必要に応じて結果修正を行います。

注記:

- Winners Round1の組み合わせ変更は、Ctrlを押しながらプレイヤー名をドラッグ&ドロップします。

### 参加者カード / 管理者カード

1. 各カードの「画像保存」で個別保存します。
2. 「全参加者+全管理者をA4シート画像で保存」で印刷用シートを生成します。

作成した参加者カードは事前に参加者に配布しておくことで、本人のみがDQ申請できる仕組みです。

## 開発環境セットアップ

### 前提

- Node.js 18+
- Rust（Tauriビルドに必要）
- Windows（ターゲット想定）

### インストール

```bash
npm install
```

### 開発起動

```bash
npm run tauri dev
```

### ビルド

```bash
npm run build
```

## 補足

- カメラ読み取りは `navigator.mediaDevices.getUserMedia` を利用します。
- 2次元バーコード検出は環境差異を考慮し、フォールバックを含む実装になっています。
