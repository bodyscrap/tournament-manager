# サバ管

Savaki式トーナメント管理アプリ、略してサバ管です。  

以下を一括管理できます。

- 各種設定での大会作成&記録
- 参加者・管理者のユーザーコード発行（2次元バーコード対応）
- アイテムリストの管理
- ブラケット進行

---

## 主な機能

アプリのタブ毎の機能を説明します。  

### 1. 大会一覧

作成済みの大会の一覧を表示します。  
ここで選択した大会が操作・閲覧の対象になります。  
また、こちらの画面から新規の大会の作成も可能です。  

### 2. アイテムリスト

アイテムリストの管理ができます。  

- アイテムリストの新規作成
- リスト名の編集
- カテゴリ名の設定
- リストへの項目の登録/編集/削除  
- 既存リストのコピー

### 3. 大会管理

大会の作成および作成した大会へのプレイヤー登録が可能です。  

**大会作成機能**  

- イベントコード (2桁) を手入力またはランダム決定
- 大会コード (4桁) を手入力またはランダム決定
- 大会名（省略時は作成日時）
- 大会形式（シングル / ダブルエリミネーション）
- 参加上限人数の設定（Max 256人）
- グランドファイナルリセットの有効/無効（ダブルのみ）
- デフォルトプレイヤーサイド（上1P / 上2P / ランダム）
- 使用キャラ入力モード（自由入力 / リスト選択）
  - リスト選択時はカテゴリを1〜3個設定でき、カテゴリごとに選択リスト・最小/最大選択数・重複禁止を指定できます

設定はブラケット作成前であれば変更可能です。  

**参加登録機能**  

- プレイヤー名・使用キャラを設定しての参加登録
  - カテゴリ別複数選択モードでは、枠ごとにスロット選択できます
- グローバル名簿からのワンクリック追加
- 参加登録済みのプレイヤー情報の編集・削除
- シード番号のランダム抽選
- シード番号の手動入れ替え
- ブラケットの生成

ブラケットは再生成可能です（再生成時は既存ブラケットを削除して作り直します）。  

**大会完了後**

- 最終順位の表示（到達レベル・得失ラウンド差・マッチ成績）
- キャラ使用率統計（リスト選択モード時）
- 大会終了(確定)後はアイテムリストを1クリックで新規作成できます（自由入力モード時）

### 4. ブラケット

ブラケット進行の管理ができます。  

- 試合状態遷移
  - 未決定 → 準備完了 → 試合中 → 結果確定
- プレイヤーサイドの設定
  - 現在の設定からの1P/2P入れ替え
  - ランダム再設定
- スコア入力&勝敗確定
- DQ機能
  - 対象参加者本人 or 管理者のユーザーコード入力で確定
- 強制敗北機能
  - 管理者のユーザーコード入力で確定
  - DQと同時指定時は強制敗北を優先
- 結果修正（勝者が変わる場合は確認ダイアログあり）
- 試合検索
  - プレイヤー名・試合状態でのフィルタ
  - ユーザーコード（手入力 / 2次元バーコード）でのプレイヤー指定
- プレイヤー途中追加
  - Winners Round1 にのみ追加可能
  - 追加後に強制敗北させれば疑似的にLosersスタートも可能
- ラウンド確定機能
  - ラウンドヘッダをクリックしてラウンド単位でロック/アンロック
  - ロック後はそのラウンドへの途中参加追加を禁止
- 対戦カード操作
  - カード内の任意の場所をクリックして試合詳細を開く
  - ブラケット画面から参加者詳細の確認・編集画面へ遷移可能
- Winners Round1 組み合わせ変更
  - Ctrl + ドラッグ&ドロップでプレイヤーの入れ替えが可能
- ユーザーコード取り込み
  - 2次元バーコードをカメラでスキャンして入力できます

### 5. ユーザーリスト

参加者・管理者を統合して管理できます。  

- 一覧表示（ID / ユーザ名 / 属性）
- 行選択
  - クリックで単一選択
  - Ctrl+クリックで複数選択
  - Shift+クリックで範囲選択
  - Ctrl+A で全選択
  - Ctrl+Shift+A で、単一選択中の属性（参加者 or 管理者）を全選択
- 各行の「ユーザーカード」ボタンでカード内容を確認
- 選択中ユーザーのユーザーカード画像保存
  - 個別保存（選択中全件を順に保存）
  - 印刷用一括保存（A4シート 1ページ10枚: 5行×2列）
  - ファイル名は `[イベントコード]_[大会コード]_[大会名]_[ユーザ名].png` および `[イベントコード]_[大会コード]_[大会名]_sheet_[ページ数]_of_[総ページ数].png`
- 管理者認証（ユーザーコード手入力 / 2次元バーコードカメラ読み取り）
- 認証済み時のみ管理者操作が可能
  - 管理者の追加
  - 管理者の編集（管理者を1名選択時のみ）
  - 管理者の削除（選択中の管理者のみ、かつ削除後に0名になる場合は不可）
- セキュリティ機能
  - 「ユーザーカード閲覧/保存を禁止」を有効化可能
  - 有効化時は確認ダイアログを表示し、復旧用として最小ID管理者のユーザーカードを先に保存
  - 禁止中は閲覧/保存ボタンが使えず、ボタンは解除用表示に切り替わる

## ユーザーコードについて

参加者と管理者にはそれぞれ固有のユーザーコード（数字列）が発行されます。  
コードは大会コード・イベントコードおよびプレイヤー情報をもとに生成され、ユーザーカードのQRコードに格納されています。  

- **参加者コード** — DQ申請（本人確認）に使用します  
- **管理者コード** — DQ申請の代理承認・強制敗北確定に使用します  

コードはカード画面に文字列として表示されるほか、2次元バーコードとしても読み取れます。  
ブラケット画面の「確認コード」欄には手入力またはカメラスキャンで入力できます。

## 画面ごとの使い方

### 大会一覧

1. 新しく大会を作成する場合は「新規作成」から進みます。
2. 既存大会を操作/閲覧する場合は一覧から選択して管理画面へ進みます。

### 大会管理

1. イベントコード・大会コード・形式・参加上限などを設定します。
2. 参加者を追加します（グローバル名簿から追加することもできます）。
3. 必要に応じてユーザーリスト画面で管理者を追加します。
4. 参加者確定後にブラケットを生成します。

注記:

- ブラケット作成後に大会管理で参加者を削除すると、警告ダイアログが表示されます。
- そのまま削除を続行した場合は既存ブラケットが削除されるため、参加者確定後に再生成が必要です。

注記:

- 試合の途中追加はブラケット画面側で行います。

### ブラケット

1. 対戦カード内の任意の場所をクリックして試合を開き、状態遷移とスコア入力を行います。
2. DQや強制敗北が必要な場合は対象スロットのボタンで設定します。
3. 確認コード欄に対象のユーザーコード（手入力または2次元バーコードスキャン）を入力して確定します。
4. 必要に応じて結果修正を行います（勝者が変わる場合は確認ダイアログが表示されます）。

注記:

- Winners Round1の組み合わせ変更は、Ctrlを押しながらプレイヤー名をドラッグ&ドロップします。
- ラウンドヘッダをクリックするとそのラウンドをロックできます。ロック解除時は対象ラウンド以降の確定も一括解除されます。

### ユーザーリスト

1. 参加者・管理者の一覧から対象ユーザーを選択します（Ctrl/Shiftで複数選択可能）。
2. 「ユーザーカード」で個別に内容確認できます。
3. 「ユーザーカード画像を保存」で選択中ユーザーを個別画像として保存します。
4. 「印刷用ユーザーカード画像を保存」でA4シート画像を生成します。
5. 管理者操作を行う場合は「管理者認証」を実施します。
6. 必要に応じて「ユーザーカード閲覧/保存を禁止」を有効化し、コード漏洩リスクを下げます。

作成した参加者ユーザーカードは事前に参加者へ配布しておくことで、本人のみがDQ申請できる仕組みです。

## 開発環境セットアップ

### 前提

- Node.js 18+
- Rust（Tauriビルドに必要）
- Windows（ターゲット想定）

### インストール

```bash
npm install
```

### 開発起動

```bash
npm run tauri dev
```

### ビルド

```bash
npm run build
```

## 補足

- カメラ読み取りは `navigator.mediaDevices.getUserMedia` を利用します。
- 2次元バーコード検出は環境差異を考慮し、フォールバックを含む実装になっています。
