# Tournament Manager

ローカル PC 上で大会を作成し、参加者と設定を管理し、ブラケット画面で試合を進行して結果を確定するためのデスクトップアプリです。

現在は 1 大会につき 1 ブラケットの構成です。複数ブラケットを統合したい場合は、複数大会を個別に進行した後、必要に応じて新しい大会を作って統一戦を手動で作成してください。

## できること

- 大会管理画面での大会の新規作成、選択、削除
- 大会管理画面での参加者追加、シード入れ替え、ランダム並び替え
- 大会設定に応じた使用キャラクターリストの作成と適用
- ブラケット画面でのシングルエリミネーション / ダブルエリミネーションの進行
- ブラケット画面での試合開始、スコア記録、DQ、結果修正、途中参加追加
- 結果確定後の閲覧専用化
- 確定済み大会から使用キャラクター一覧を新規リスト化

## 起動方法

### 必要環境

- Node.js
- Rust
- Tauri のビルドに必要な環境

### 開発用に起動する

```bash
npm install
npm run tauri dev
```

### フロントエンドをビルドする

```bash
npm run build
```

## 基本的な使い方

### 1. 大会を作成する

左メニューの大会一覧から新規作成を選び、以下を設定します。

- 大会名
- トーナメント形式
- 参加上限
- グランドファイナルリセットの有無
- デフォルトプレイヤーサイド
- 使用キャラ設定

使用キャラ設定は次の 2 つがあります。

- 自由入力: キャラ名を自由に入力
- リストから選択: 大会専用の使用可能キャラだけを選択

### 2. 使用キャラクターリストを作る

左メニューの使用キャラリストから、キャラクター一覧を 1 行 1 件で登録できます。

主な操作:

- 新規作成
- 編集
- 複製
- 削除

大会作成時や大会設定変更時に、このリストを大会へ取り込めます。

### 3. 参加者を登録する

大会管理画面で参加者を追加します。ここで登録した参加者がブラケットの初期構成に使われます。

- 名前を直接入力して追加
- 既存名簿から追加
- 使用キャラを大会ルールに合わせて設定
- シード順の入れ替え
- シードのランダム化

参加者が 2 名以上になったらブラケットを生成できます。

### 4. ブラケットを生成する

大会管理画面でブラケット生成を実行すると、大会は進行中になります。以後の試合操作はブラケット画面で行います。

注意:

- 既存のブラケットは生成時に作り直されます
- 現在は 1 大会につき 1 ブラケットです

### 5. 試合を進行する

ブラケット画面では各試合カードをクリックして操作します。

試合カードの見方:

- 各カードは 1 試合を表します
- カード内には対戦者、サイド、スコア、状態が表示されます
- 未確定の相手や配線待ちがあるカードは、決定前の状態として表示されます

主な流れ:

1. 組み合わせが確定すると試合が準備完了になります
2. 必要ならキャラやサイドを確認します
3. 試合中にする
4. スコアや DQ を入力して結果を確定する

状態の遷移:

1. 未決定: 組み合わせがまだ確定していません
2. 準備完了: 対戦者が揃い、開始前の確認ができます
3. 試合中: 実際に試合を進行している状態です
4. 結果確定: 勝敗が確定し、次の試合へ結果が反映されます

補足:

- 組み合わせが未確定のカードは未決定と表示されます
- プレイヤーサイドは準備完了になるまで未確定です
- 未確定のサイドはグレーの `-` 表示になります
- 試合結果は後から修正できます

### 6. 途中参加や追加試合に対応する

進行中の大会では、ブラケット画面から追加操作ができます。

- プレイヤー途中追加
- 試合の手動追加

ダブルエリミネーションでは、途中参加の配線や敗者側の送り先も考慮してブラケットを補完します。

### 7. 大会を終了・確定する

全試合が終わると大会は完了状態になります。大会管理画面で結果を確定すると、その大会は閲覧専用になります。

結果確定後にできること:

- 最終順位の確認
- 使用されたキャラクター一覧から新しい使用キャラリストを作成

## 画面一覧

### 大会一覧

- 大会の選択
- 新規大会作成への移動
- 大会の削除
- 現在の状態確認

### 使用キャラリスト

- キャラクターリストの作成・編集・複製・削除

### 大会管理

- 大会設定の作成・変更
- 参加者登録
- シード調整
- ブラケット生成
- 結果確定

### ブラケット

- 試合カードの一覧表示
- 試合検索
- 試合開始
- スコア記録
- DQ 記録
- 結果修正
- プレイヤー途中追加
- ラウンド確定 / 解除

## 状態の見方

- 設定中: 参加者や大会設定を調整している状態
- 進行中: ブラケット生成後に試合を進行している状態
- 完了: 全試合終了済みだが、まだ最終確定していない状態
- 結果確定済: 閲覧専用の最終状態

## 現在の仕様メモ

- 1 大会 = 1 ブラケット
- 複数ブラケットを 1 大会内で並行管理する機能はありません
- 複数大会の勝者をまとめたい場合は、新しい大会を作って統一戦を手動作成してください
- 使用キャラをリスト選択制にした大会では、参加者と試合のキャラ入力はそのリスト内に制限されます

## データについて

このアプリはローカル環境で大会データを扱います。テスト運用中は、重要な大会を扱う前にデータのバックアップ方針を決めておくことを推奨します。
